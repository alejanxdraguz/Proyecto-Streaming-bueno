Este programa en C# simula un sistema de evaluación de contenido para una plataforma de streaming. A través de un menú interactivo, permite al usuario ingresar datos de distintos contenidos (como tipo, duración, clasificación por edad, horario y nivel de producción) y verificar si cumplen con ciertas reglas establecidas. Según estas condiciones, el sistema decide si el contenido se publica, se rechaza o se envía a revisión, además de clasificar su impacto como alto, medio o bajo. También lleva un control estadístico de todos los contenidos evaluados, mostrando datos como total procesado, aprobados, rechazados, porcentaje de aprobación e impacto predominante. Finalmente, incluye opciones para visualizar las reglas del sistema y reiniciar las estadísticas acumuladas.
